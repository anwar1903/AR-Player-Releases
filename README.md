# AR-Player — Official Releases

**AR-Player** is a fast, lightweight, **100% offline-first** desktop media player for Windows 10 / 11 (x64), built with **Tauri v2**, **Rust**, **React**, and **libmpv**. Engineered with Direct3D 11 (`d3d11va`) hardware acceleration, it delivers smooth playback of heavy `.mkv` movies and `.flac` music with minimal RAM overhead.

🌐 **Official Website & Direct Download:** [anwar1903.github.io/AR-Player-Releases](https://anwar1903.github.io/AR-Player-Releases/)

---

## Highlights

* **Hardware-Accelerated Playback:** Smooth Direct3D 11 (`d3d11va`) GPU video decoding across `.mkv`, `.mp4`, `.avi`, `.mov`, `.webm`, and more.
* **100% Offline & Private:** Works completely offline with zero accounts, telemetry, or background network calls during playback.
* **Music Mode & Mini-Player (`W`):** Automatic audio metadata and embedded album cover art extraction (`.mp3`, `.flac`, `.opus`, `.wav`, `.m4a`) with an always-on-top compact mode.
* **Folder Queues & Auto-Resume:** Drag and drop files or entire folders to queue playback, with automatic local resume memory for long movies.
* **Subtitle & Audio Control:** Switch embedded tracks (`B` / `V`), auto-load external `.srt` / `.ass` subtitles, and fine-tune subtitle sync (`G` / `H`, reset with `Shift + G`).
* **Cryptographically Signed Updates:** Releases are signed with Ed25519 keys and verified automatically by the built-in updater.

## Installation (Windows 10 / 11 64-bit)

1. Download the latest **`AR-Player_<version>_x64-setup.exe`** from the [Official Download Page](https://anwar1903.github.io/AR-Player-Releases/) or the [Releases](https://github.com/anwar1903/AR-Player-Releases/releases/latest) tab.
2. Run the installer to install **AR-Player**.
3. *(Optional)* Right-click any video or audio file in Windows Explorer → **Open with** → **Choose another app** → select **AR-Player** and click **Always**.
